# Theme tokens

Every variable declared in `ui/src/styles/kiwi-theme.css`, read from the stylesheet, so a new token appears here on its own. Components use these through Tailwind utilities or `var(--…)`; `kiwi-app` blocks receive them too, and the kit maps them onto its `--k-*` tokens.

## Palettes

Workspace palettes override a subset of the tokens. Each is shown in light and dark.
